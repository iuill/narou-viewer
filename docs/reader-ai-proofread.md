# 本文AI校正

## 目的

本文に含まれる不自然な改行、空白、段落分割を、原文の内容と文体を維持したまま読みやすく表示する。AI校正版は読者向けの表示補助であり、作者による修正版や取得本文の正本として扱わない。

## 導線

- 本文画面の「読書設定」から「本文校正」を開く。
- 「AIによる読みやすさ補正」の「この話をAI校正」で現在話を生成する。
- 生成後は「原文」と「AI校正版」を切り替えられる。
- AI校正版の表示中は本文画面に状態バッジを表示し、バッジから原文へ戻せる。
- 確認ダイアログは追加しない。外部 LLM provider への送信については README と「AI機能 > 設定」の共通説明を正本とする。

## 校正範囲

- 初期実装は、現在話を利用者が明示的に実行する。
- LLMには不自然な改行、空白、段落分割だけを保守的に修正させる。
- 語彙、文体、台詞、固有名詞、意味、句読点、表記の変更を指示しない。
- 意図的か判断できない箇所は原文を維持する。
- reader documentのうち、`text` と `lineBreak` だけで構成された連続段落を校正対象にする。ルビ、リンク、縦中横、画像、HTML fallbackを含む部分は構造保持を優先して対象外にする。
- 本文なしで`lineBreak`だけを持つ空行段落は、意図的な間として原文の位置と個数を保持する。空行をまたいだ段落結合は行わない。
- 句点、感嘆符、疑問符、閉じ括弧の位置にある段落境界は、AI出力で変わっていても原文の境界へ復元する。原文にあれば保持し、なければ新設しないことで、作者ごとの一文一段落・複数文一段落の書き方を維持する。
- 日本語文中に孤立して混入した不自然な空白は、LLMが文脈から判断して削除する。英単語間、ASCII表現、字下げ、意図的な間や強調などの可能性がある空白は維持する。
- 原文段落先頭の全角スペースを含む字下げは、AI出力でも同じ位置と空白列を保持する。段落内改行はreader documentの`lineBreak`へ復元して表示する。
- AI校正版の表示時にも、引用符、連続ハイフン、半角括弧、半角英数字・記号の通常校正を後段で適用する。通常校正設定の変更にAI再生成は不要とする。

## データ境界

- `novel-fetcher` の保存データ、raw HTML、取得済み本文は変更しない。
- AI校正版は `data/state/reader_ai_proofreads/` 配下の再生成可能な派生データとして、話単位で保存する。
- 保存結果は原文のcontent ETagとprompt versionに紐づける。いずれかが変わった結果は表示に使わない。
- 生成失敗、出力schema不整合、対象本文の欠落時は原文を維持する。
- 生成リクエストは既存のactive OpenRouter profileを利用し、AI利用履歴にはfeature `reader_proofread` とtoken集計を記録する。prompt、校正前本文、校正後本文はusage snapshotへ保存しない。
- 同じ話への生成が同時に要求された場合は、先行リクエストの結果を共有してLLMへの重複送信を避ける。
- AI出力がJSON構造、本文文字列、段落構造の安全検証に失敗した場合は、最初の入力と失敗した出力を同じモデルへ渡し、非空白文字を原文へ戻すよう1回だけ再校正する。再校正も同じ安全検証を通過しなければ保存しない。
- 1話は文脈を維持するため分割せず、初回は1回のLLMリクエストで扱う。安全検証時の再校正だけは追加の1回を許可する。モデルの出力上限を超えた場合は保存せず、出力上限の大きいモデルを選ぶよう画面へ案内する。

## API

- `GET /api/library/novels/{novelId}/episodes/{episodeIndex}/ai-proofread`
  - 現在の原文に対応する校正版の有無と、生成済みの場合はreader documentを返す。
- `POST /api/library/novels/{novelId}/episodes/{episodeIndex}/ai-proofread`
  - 現在話を校正し、派生データを保存して返す。
- `DELETE /api/library/novels/{novelId}/episodes/{episodeIndex}/ai-proofread`
  - 保存済みのAI校正版を削除する。原文には影響しない。
